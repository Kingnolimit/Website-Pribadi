# Website Pribadi

Website pribadi sederhana yang dibuat untuk menampilkan profil, keahlian, proyek, dan kontak.

## Fitur

- Layout satu halaman
- Desain responsif
- Dark mode modern
- Navigasi mobile
- Section profil, keahlian, proyek, dan kontak

## Cara menjalankan

Buka file `index.html` di browser secara langsung, atau jalankan server lokal dengan perintah berikut:

```bash
python -m http.server 8000
```

Lalu buka http://localhost:8000

## Struktur file

- `index.html` — halaman utama
- `styles.css` — styling situs
- `script.js` — interaksi kecil seperti menu mobile dan tahun footer
